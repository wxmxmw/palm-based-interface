# Meta Quest 3 手势 MR 界面需求设计文档

## 1. 目标与范围

构建一个运行在 Meta Quest 3 上的最小混合现实（MR）应用。应用使用头显透视画面作为背景，用户全程不使用控制器，仅通过双手追踪完成界面的显示、隐藏与点击操作。

本版本仅包含：

- 可显示/隐藏的用户界面；
- 一个信息显示面板；
- 两个可点击按钮；
- 右手“掌心朝上、手掌张开”手势触发；
- 捏合手势点击。

不包含空间锚点、环境网格/遮挡、真实物体交互、多窗口、语音、账号、网络或持久化功能。

## 2. 运行环境与前提

- 目标设备：Meta Quest 3。
- 呈现模式：MR 透视（Passthrough），应用背景透明，用户可看见周围真实环境。
- 输入方式：Meta 手部追踪；不依赖或要求控制器。
- 用户需在头显系统中授予应用使用手部追踪与透视画面的权限。

## 3. 用户流程

1. 应用启动后进入 MR 透视视图，界面默认显示。
2. 用户抬起右手，使手掌张开且掌心大致朝上。
3. 系统识别该手势后，在用户前胸正前方隐藏界面。
4. 用户再次执行右手“掌心朝上、手掌张开”手势，系统显示界面。
5. 用户将手部指针移动到按钮上，以拇指与食指捏合完成点击。

## 4. 功能需求

### 4.1 透明 MR 背景

- 应用必须启用 Quest 3 的 Passthrough 能力。
- 不渲染不透明天空盒、背景平面或全屏遮罩。
- 系统不读取、不识别、不修改真实环境；真实世界仅作为可见背景。

### 4.2 界面激活与隐藏

- 初始状态：界面显示。
- 触发手：仅右手。
- 有效姿态：右手位于用户胸前或更高位置；五指处于展开状态；掌心法线方向与世界上方的夹角不大于 45°。
- 满足姿态并连续保持至少 0.7 秒后，切换界面显示状态：隐藏→显示，显示→隐藏。
- 每次切换后进入 1 秒冷却期，冷却期间忽略同一触发姿态，防止重复切换。
- 手部追踪短暂丢失或置信度不足时，不改变当前界面状态。

### 4.3 界面内容与布局

- 界面由一个信息显示面板和两个按钮组成。
- 面板显示一条可配置的简短文本；默认文案为“系统已激活”。
- 按钮显示文本“按钮 1”和“按钮 2”。
- 界面为 Torso-Locked Panel（躯干锁定面板）：首次显示时位于用户前胸正前方约 0.8/1.0 米处，面板正面朝向用户；显示期间其位置与朝向随用户前胸部（躯干）平滑跟随，不随头部的单独移动或转向而改变。
- 面板与控件应具备足够对比度、清晰边框和适合近距阅读的字号；不遮挡整个视野。

### 4.4 无控制器手势交互

- 界面显示时启用手部射线/指尖指针；隐藏时禁用全部 UI 交互。
- 用户以拇指与食指捏合表示一次点击。
- 当指针悬停在按钮上时，按钮显示明显的悬停反馈；捏合被识别后显示按下反馈。
- 每次完整捏合仅触发一次按钮点击；必须先松开后才能再次点击。
- “按钮 1”“按钮 2”点击后分别调用各自预留的本地事件回调；本需求不定义任何额外业务行为。

## 5. 状态与优先级

| 状态 | 可见性 | 可交互性 | 进入条件 |
| --- | --- | --- | --- |
| 隐藏 | 不显示面板与按钮 | 不可交互 | 启动，或显示状态下触发激活手势 |
| 显示 | 显示面板与两个按钮 | 可捏合点击 | 隐藏状态下触发激活手势 |
| 切换冷却 | 保持切换后的可见状态 | 按当前可见状态决定 | 状态切换后的 1 秒内 |

## 6. 验收标准

1. 在 Quest 3 上启动后，用户能看到真实环境，且界面默认显示。
2. 右手掌心朝上并张开、稳定保持 0.7 秒，可隐藏界面；再次执行同一手势可显示界面。
3. 单次持续手势不会造成连续显示/隐藏切换，松手后且冷却结束才能再次触发。
4. 不连接控制器时，用户可通过手部指针悬停并用拇指—食指捏合分别点击两个按钮。
5. 隐藏状态下按钮不可见、不可响应；手部追踪丢失不会误触发状态切换或点击。
6. 界面显示期间，其位置与朝向随用户前胸部（躯干）移动和转向而跟随；用户仅移动或转动头部时，界面不随头部改变位置或朝向。
7. 应用不提供任何真实环境物体的识别、选择、遮挡或交互能力。

## 7. 实现约束

- 使用 Meta Quest 3 支持的 Passthrough 与 Hand Tracking API/SDK 实现。
- 手势阈值、保持时长和冷却时长应配置化，便于在设备上调优。
- 激活手势识别应与 UI 捏合点击分离：激活姿态用于控制界面状态，捏合仅在界面显示时用于操作控件。
